# trabalho-eng-software

## Trabalho de Engenharia de Software

Este repositório foi criado para o desenvolvimento da atividade prática de Engenharia de Software.

### Estrutura de Branches

- `main` — branch principal do projeto.
- `dev` — branch de desenvolvimento.
- `feature/readme` — branch destinada às alterações do README.

### Equipe

Projeto desenvolvido em equipe para aplicação de conceitos de Git e GitHub, incluindo branches, commits e Pull Requests.
